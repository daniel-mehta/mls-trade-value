# Data Notice

This project includes a static MLS player-statistics snapshot generated from the
free public American Soccer Analysis (ASA) API. The browser does not call ASA or
any other player-data service during normal use.

The snapshot may include player identity, team, position, current- and
previous-season statistics, and salary figures when ASA provides them. It does
not include player images, MLS roster designations, contract terms, option
years, or personal user data.

The data is a point-in-time statistical snapshot, not official MLS data. It can
be incomplete, delayed, or affected by transfers and source updates. In
particular, a recently transferred player may temporarily display the club for
which they recorded the most current-season minutes.

Salary data is optional. When ASA provides multiple MLSPA salary releases for a
player, the latest release is used; salary values are never summed.

American Soccer Analysis is the underlying data source. Review ASA's current
terms and attribution guidance before republishing or redistributing a refreshed
dataset.
